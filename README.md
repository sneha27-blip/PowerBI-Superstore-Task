Power BI Superstore Sales Dashboard

Overview
Created an interactive Power BI dashboard using the Superstore dataset to analyze sales performance and identify key business insights.

 What I Did
* Created KPI cards for Total Sales, Total Profit, and Total Quantity.
* Created a Sales by Category visualization.
* Created a Sales by Region visualization.
* Created a Sales by Customer Segment visualization.
* Applied clean and simple visual formatting.
* Highlighted key business insights.
* Created a summary page/storyboard.

Key Business Insights
* Technology is the highest-selling category.
* West is the highest-selling region.
* Consumer is the highest-selling customer segment.

Tools Used
* Microsoft Power BI
* Superstore Dataset

Files Included
* Power BI dashboard (`.pbix`)
* Superstore dataset
* README.md

Objective
To use data visualization and business insights to understand sales performance and present the findings through an interactive Power BI dashboard.
